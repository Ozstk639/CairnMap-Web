## 可编辑性与明确例外

[参数账本](../../scripts/config-tools/fixtures/v3-parameter-ledger.json) 的 673 项包括嵌套结构和 union 分支，不等于 673 个独立 UI 控件。其中 528 项归为有编辑入口与能力族消费证据；22 项由系统维护；61 项是旧包兼容来源记录；其余为受控目录、生成来源报告、诊断/导入类型或受限制取值。

“能力族通过”不等于每项高级参数全部取值均完成浏览器操作。账本明确给出编辑、消费、校验、序列化、默认与继承来源；没有把全文搜索字段名当作逐参数验收证明。World、身份、几何序列化、系统页面与安全表达式边界继续受系统约束，用户可编辑合法显示、输入与组装参数。

旧 `advanced`/`legacy` 原始来源、`sourceRuntimeField`、`scenes.editor/search` 等兼容记录不作为原生执行开关；UI 已去掉会造成误解的场景开关。`scenes.workflow` 控制新输入的可用字段，`scenes.infocard` 控制自动补充信息卡。未实现的 legacy/debug fallback 取值不能保存为有效原生配置。

明确允许的例外：三种整体 external 工作流、TRP 专用卡、World canonical ID、英文空值独立、BUD/STB 真几何点实现。其他标准工作流没有新增 external 逃生通道。

因此，当前已实现目标配置和新增设置能力，并在上述固定场景中再现 V1。不能据此宣称任意历史脏数据、任意组合状态、任意用户改值都已穷尽验证；首次转正门仍包含用户对真实项目数据与交互的人工确认。
