### 4.5 BUD 点 + Label 等效果再现（BP06）

这是本轮用户再次确认的重点。**实现采用真实 V3 几何点；效果验收不再以“点存在、锚点一致”就通过。** STB 等同机制分类纳入相同核对，但逐类来源独立确认。

已观测 ISP/TPP 2500→5000、ISL 3800→7600、ISG 5000→10000、ROD 3600→3610；目标恢复冻结 V1 有效值和排序，不把这些单点值作为所有分支的默认常量。

补齐编辑器八项已确认缺失：candidateOffsetsPx、collideWith、blocks、keepPreviousAnchor、invalidateWhen、reduceOrder、preserveSelected、preserveRequired。审计全部现有扩展的消费者；源码出现字段名不算生效。

候选顺序、缩写/隐藏/强制显示、障碍类别、密度降级、世界切换/文本变化/几何变化的失效必须同输入对照。采用混合类别重叠、优先/普通建筑、屏幕边缘、多部件、缩放与连续平移场景；单要素截图不能证明取舍一致。

### 4.8 交互态完整迁移与实际事件（BP09）

把 V1 的点图钉、道路 nav-outline、面高亮等迁移成包内通用 profile；全局默认复用，几何或规则真实例外用受控引用/覆盖。

- hover/selected/searchResult/editing/deletionMarked 都接实际状态来源与真实鼠标事件；定义多态同时存在时的优先级，以冻结 V1 的实际行为作参照。
- enabled=false 只关闭对应视觉副作用，不能继续走 labelClick 的无条件高亮。开卡/选择、Label 强显、zIndex、样式各有清晰职责。
- 图钉不是等尺寸 CircleMarker；nav-outline 必须呈现外白线+内主色线。编辑颜色/尺寸/线宽后真实效果跟随。
- 几何、边界、内部、Label、图片的点击触发能力按配置消费；偏移、多部件与仅标签命中返回原 record，不生成另一个信息卡身份。
- 正常选中/取消、hover 离开、搜索撤销、编辑结束、删除标记恢复都清除临时覆盖并恢复正常规则。

### 4.9 信息卡完整迁移（BP10）

标准卡继续使用 V3 编辑器和组装器。冻结 V1 卡片行构造、最终文字、分区/顺序、链接对象与点击行为，不只比较对象 JSON。

- 增加可编辑“分类语义行”，由分类链本身解析中文/英文和显示范围；保留“类型：室内道路”等 V1 效果，不硬编码每条分类的文案。
- 补 ID、Name、World、Type、创建时间、创建者等系统行及“其他信息”，配置字段顺序/空值隐藏。系统值仍自动维护，展示可以编辑。
- 对剩余 fields/tags/extensions 提供可编辑策略、排除/排序，已展示字段不重复；未知旧字段按 V1 明确策略显示。
- boolean/enum/number/date/JSON、外链文本与地址、关系匹配/展示/点击、图片与线路胶囊完整标准化。旧 Card plain 字段不得因有 reference 自动升级为可点击链接；按 V1 实际卡片字段设置。
- 标准卡导出、重导入后的行和交互保持。现有 34 条记录逐一对照，另补所有非这批工作流产生的显示分类及外部工作流覆盖分类。

### 4.10 保存、导入、升级、激活和参数完整生效（BP11）

当前 Config Lab saveLocal/importFile 没有先阻断无效整包。统一工作台、工作流保存、Lab、本地历史、JSON/ZIP 导入、运行激活的校验门。

- 导入先读取/升级到隔离草案，再校验；失败可以查看诊断/继续编辑，但不能覆盖已保存有效版本或成为 active package。
- 加载缓存/历史版本也校验；未知契约/未知参数/缺消费者不得悄悄降级。显式“未支持”不计可用功能。
- 既有用户编辑版本用可审计升级/差异清单迁移，保留用户覆盖；不得通过重新生成 V1 默认包覆盖所有本地编辑。冲突在编辑器定位，不静默丢弃。
- 全局默认 → 包/几何 profile → 分类继承 → Zoom 规则 → 条件覆盖 → 交互态的有效值与来源可查看；保存后主图、预览、Runner 读取同一版本。

- UI 修改、校验、保存、导出、重导入、激活、实际运行构成每项参数的验收链。不得只统计“类型字段在编辑器代码里被引用”。
